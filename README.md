# Swiss glacier retreat explorer

This project develops a reproducible geospatial workflow in R to explore glacier retreat in Switzerland using glacier outlines from the GLIMS Glacier Database.

The workflow downloads and processes glacier outlines, computes ice-cover area change, visualises glacier evolution through time, and provides an interactive Shiny application.

## Main outputs

-   A Quarto HTML report describing the workflow, results and limitations.
-   An interactive Shiny application to explore individual glacier retreat.
-   Leaflet maps and diagnostic statistics on the retained glacier dataset.

## Online Shiny application

The Shiny application is available here:

<https://mdaman.shinyapps.io/swiss-glacier-retreat/>

## Repository structure

-   `LGEO2185_glacier_retreat.qmd`: main Quarto report and workflow
-   `R/shiny_app.R`: Shiny application source code
-   `styles.css`: custom styling for the Quarto document
-   `outputs/figures/`: figures used in the report

## How to run the project

1.  Open `LGEO2185_glacier_retreat.Rproj` in RStudio.
2.  Open `LGEO2185_glacier_retreat.qmd`.
3.  Render the Quarto document.

The raw data are not included in this repository. They are downloaded or generated by the workflow.
